# TEACHER_GUIDE

## Apa itu EcoGuard

Game edukasi lingkungan untuk SD/SMP — belajar lewat misi, bukan hanya soal.

## Cara Menjalankan

`npm install && npm run dev` → buka localhost:5173 → Try Demo tanpa login.

## Penjelasan Level

Lihat GAME_DESIGN.md — tiap level punya materi, gameplay, dan refleksi edukatif setelah misi.

## Membaca Skor

Level (XP/300 per level), Eco Points, Misi selesai, Badge, Quiz score. Progress bar per indikator.

## Dashboard Guru

- Student Progress tabel
- Mission/Quiz Management (edit `src/data/`)
- Class & Leaderboard (opsi nama samaran untuk privasi)
- Report per topik + Export CSV/PDF

## Ide Aktivitas Setelah Bermain

- Level Karhutla: diskusi "Apa yang dapat kita lakukan untuk mengurangi risiko kebakaran lingkungan?"
- Level Daur Ulang: praktik pilah sampah di kelas
- Level Penghijauan: tanam bibit di kebun sekolah
